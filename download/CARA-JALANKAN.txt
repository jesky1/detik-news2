============================================================
  PANDUAN CARA MENJALANKAN DETIKNEWS PORTAL
============================================================

PERSYARATAN:
1. Node.js (versi 18 atau lebih baru)
   - Download di: https://nodejs.org/
   - Pilih versi LTS (Long Term Support)
   - Setelah install, cek di CMD/PowerShell:
     node --version
     npm --version

2. Pastikan komputer terhubung internet
   (karena berita diambil langsung dari detik.com)

============================================================
LANGKAH-LANGKAH:
============================================================

1. EKSTRAK FILE ZIP
   - Klik kanan file detik-news-project.zip
   - Pilih "Extract All" atau "Extract Here"
   - Atau gunakan aplikasi WinRAR/7-Zip

2. BUKA CMD / TERMINAL DI FOLDER PROJECT
   - Buka File Explorer, masuk ke folder yang sudah di-extract
   - Klik di address bar, ketik "cmd", lalu tekan Enter
   - Contoh: C:\Users\Nama\Downloads\detik-news-project> 

3. COPY FILE .ENV
   copy .env.example .env

4. INSTALL DEPENDENCIES
   npm install
   (tunggu sampai selesai, bisa 1-3 menit)

5. SETUP DATABASE
   npx prisma generate
   npx prisma db push

6. JALANKAN SERVER
   npm run dev

7. BUKA BROWSER
   - Buka Chrome/Edge/Firefox
   - Ketik di address bar: http://localhost:3000
   - Web DetikNews Portal akan terbuka!

============================================================
KALAU ADA ERROR:
============================================================

Error: "'npm' is not recognized"
  -> Node.js belum terinstall. Download dan install dari nodejs.org

Error: "'npx' is not recognized"
  -> Node.js belum terinstall. Download dan install dari nodejs.org

Error: "port 3000 is already in use"
  -> Port 3000 sedang dipakai. Tutup aplikasi lain atau:
     npx next dev -p 3001
     lalu buka http://localhost:3001

Error: "Prisma Client not generated"
  -> Jalankan: npx prisma generate

Error: Berita kosong / tidak muncul
  -> Pastikan komputer terhubung internet
  -> Coba refresh halaman
  -> detik.com mungkin sedang down

============================================================
CATATAN:
============================================================
- Berita diambil secara REAL-TIME dari detik.com
- Web ini berfungsi sebagai portal berita yang meng-scrape
  artikel dari berbagai kanal detik.com
- Data tidak disimpan di database (langsung dari detik.com)
- Pastikan internet aktif saat menggunakan web ini
